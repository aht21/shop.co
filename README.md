## Shop.co
The app is a basic clothing store, including a main promo page, a product list with filters, and a shopping cart.

### Project structure
Dev stack: JavaScript + React.

File Structure:
- ```/components``` - all components used in the project,
- ```/data``` - mocked data about products,
- ```/resources``` - used assets,
- ```/services``` - hooks implementing the main entities and their methods.

### How to launch the application
```
npm i
npm run start
```
